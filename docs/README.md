# Документація проєкту Kadrbox

Ця директорія містить архітектурну, технічну документацію та звіти аудиту медіаплеєра
**Kadrbox**.

> **Актуальна модель.** Kadrbox — це кросплатформний медіаплеєр, який синхронізує прогрес
> перегляду між пристроями та забезпечує спільний перегляд (Watch Party). Каталог і потоки
> застосунок отримує з **каталогового сервера**, URL якого користувач вводить сам. Застосунок
> не містить контентних парсерів. Див. [`../MIGRATION_REPORT.md`](../MIGRATION_REPORT.md).

---

## ⚠️ Актуальність документації

> **Джерело істини щодо стеку — [`../README.md`](../README.md).** Розділи 01-05 нижче було
> написано **до** розділення відповідальності між застосунком і зовнішніми джерелами, тому
> вони позначені як історичні:
>
> | Застаріле твердження | Реальність |
> |---|---|
> | Авторизація, синхронізація та Watch Party на PocketBase | Go-бекенд у `backend/`: JWT + PostgreSQL 16 + Redis |
> | Парсинг у Dart та у Go-бекенді | Парсерів немає ніде; каталог приходить з каталогового сервера, URL якого задає користувач |
> | WebRTC / PocketBase Realtime для Watch Party | Go WebSocket hub + Redis |
> | Web (beta) | Не підтримується — каталогу `web/` немає |
>
> Розділи **не переписані** повністю, а позначені як історичні; посилання на конкретних
> джерелах прибрано, архітектурний зміст збережено.
